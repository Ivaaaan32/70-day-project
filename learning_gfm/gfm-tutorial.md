# GFM: краткий учебник-чеклист

GFM (GitHub Flavored Markdown) — это CommonMark плюс расширения. Фичи идут от простых к нишевым. Отмечайте `[x]` то, что уже освоили.

> Пометки: **[GFM]** — расширение GFM, **[GitHub]** — работает только на GitHub, остальное есть в обычном Markdown.

---

## Уровень 1. Основы

- [x] **Заголовки** — от `#` до `######`

  ```markdown
  # Заголовок 1
  ## Заголовок 2
  ###### Заголовок 6
  ```

- [ ] **Абзацы и переносы строк** — абзацы разделяет пустая строка; перенос внутри абзаца: два пробела или `\` в конце строки

  ```markdown
  Первая строка\
  Вторая строка

  Новый абзац
  ```

- [ ] **Курсив, жирный** — звёздочки или подчёркивания

  ```markdown
  *курсив*  **жирный**  ***оба сразу***
  ```

- [ ] **Маркированные списки** — `-`, `*` или `+`; вложенность задаётся отступом

  ```markdown
  - яблоко
  - груша
    - вложенный пункт
  ```

- [ ] **Нумерованные списки** — цифры с точкой, реальные номера не важны

  ```markdown
  1. первое
  2. второе
  3. третье
  ```

- [ ] **Ссылки** — текст в `[]`, адрес в `()`

  ```markdown
  [Сайт GitHub](https://github.com "Всплывающая подсказка")
  ```

- [ ] **Картинки** — как ссылка, но с `!` в начале

  ```markdown
  ![Описание](images/cat.png)
  ```

- [ ] **Цитаты** — символ `>`

  ```markdown
  > Это цитата
  >
  > > Вложенная цитата
  ```

- [ ] **Код в строке** — обратные кавычки

  ```markdown
  Запустите `npm install` в терминале.
  ```

- [ ] **Горизонтальная линия** — три и более `-`, `*` или `_`

  ```markdown
  ---
  ```

## Уровень 2. Самые частые расширения GFM

- [ ] **Блоки кода с подсветкой [GFM]** — тройные кавычки и название языка

  ````markdown
  ```python
  def hello():
      print("Привет")
  ```
  ````

  Чтобы показать тройные кавычки внутри блока, оберните его в четыре обратные кавычки.

- [ ] **Зачёркивание [GFM]** — две тильды

  ```markdown
  ~~старая цена~~ новая цена
  ```

- [ ] **Таблицы [GFM]** — столбцы через `|`, вторая строка из `---` обязательна; двоеточия задают выравнивание

  ```markdown
  | Слева | По центру | Справа |
  |:------|:---------:|-------:|
  | a     | b         | c      |
  | 1     | 2         | 3      |
  ```

  Внутри ячейки вертикальную черту экранируйте: `\|`.

- [ ] **Чекбоксы (списки задач) [GFM]** — `[ ]` и `[x]` после маркера списка

  ```markdown
  - [x] Сделано
  - [ ] В планах
  ```

  На GitHub в issue и PR их можно отмечать кликом.

- [ ] **Автоссылки [GFM]** — голый URL становится ссылкой без разметки

  ```markdown
  https://github.com  или  <https://github.com>
  ```

- [ ] **Экранирование** — обратный слэш отменяет спецсимвол

  ```markdown
  \*не курсив\*   \# не заголовок
  ```

## Уровень 3. Продвинутое

- [ ] **Ссылочные ссылки** — URL выносится в конец документа, удобно для повторов

  ```markdown
  Читайте [документацию][docs] или [спеку][spec].

  [docs]: https://docs.github.com
  [spec]: https://github.github.com/gfm/
  ```

- [ ] **Якоря на заголовки** — GitHub генерирует id: строчные буквы, пробелы → `-`, знаки препинания убираются

  ```markdown
  [К разделу про таблицы](#уровень-2-самые-частые-расширения-gfm)
  ```

- [ ] **Эмодзи-коды [GitHub]** — двоеточия вокруг названия

  ```markdown
  :tada: :rocket: :+1:
  ```

- [ ] **Встроенный HTML** — когда синтаксиса не хватает

  ```markdown
  Нажмите <kbd>Ctrl</kbd> + <kbd>C</kbd>. H<sub>2</sub>O, x<sup>2</sup>.
  ```

  GFM отфильтровывает опасные теги (`<script>`, `<iframe>`, `<style>`, `<textarea>` и др.).

- [ ] **Комментарии** — не отображаются на странице

  ```markdown
  <!-- Это увидят только в исходнике -->
  ```

- [ ] **Сворачиваемые блоки [GitHub]** — HTML-теги `details` и `summary`

  ```markdown
  <details>
  <summary>Нажмите, чтобы раскрыть</summary>

  Скрытое содержимое. Пустая строка выше нужна, чтобы Markdown внутри работал.

  </details>
  ```

- [ ] **Упоминания и ссылки на объекты [GitHub]** — работают в issue, PR, обсуждениях

  ```markdown
  @username   #123   user/repo#45   a5c3785
  ```

  Упоминание уведомляет человека, `#123` ссылается на issue или PR, хеш превращается в ссылку на коммит.

- [ ] **Сноски [GitHub]** — маркер в тексте и определение внизу

  ```markdown
  Здесь важное утверждение[^1].

  [^1]: А это пояснение к нему.
  ```

- [ ] **Блоки-предупреждения (alerts) [GitHub]** — цитата со специальным маркером

  ```markdown
  > [!NOTE]
  > Полезная информация.

  > [!WARNING]
  > Критически важное предупреждение.
  ```

  Типы: `NOTE`, `TIP`, `IMPORTANT`, `WARNING`, `CAUTION`.

## Уровень 4. Редкое и нишевое

- [ ] **Математика (LaTeX) [GitHub]** — доллары для строчных формул, двойные для блочных

  ```markdown
  Строчная формула: $E = mc^2$

  $$
  \int_0^1 x^2 \, dx = \frac{1}{3}
  $$
  ```

- [ ] **Диаграммы Mermaid [GitHub]** — блок кода с языком `mermaid`

  ````markdown
  ```mermaid
  graph LR
    A[Идея] --> B[Код] --> C[Релиз]
  ```
  ````

- [ ] **Карты GeoJSON и TopoJSON [GitHub]** — блок кода с языком `geojson`

  ````markdown
  ```geojson
  {
    "type": "Point",
    "coordinates": [60.6, 56.84]
  }
  ```
  ````

- [ ] **3D-модели STL [GitHub]** — блок кода с языком `stl`

  ````markdown
  ```stl
  solid cube
    facet normal 0 0 0
      outer loop
        vertex 0 0 0
        vertex 1 0 0
        vertex 0 1 0
      endloop
    endfacet
  endsolid
  ```
  ````

- [ ] **Цветовые образцы [GitHub]** — в issue, PR и обсуждениях код цвета в обратных кавычках показывает кружок с цветом

  ```markdown
  `#ff0000`  `rgb(0, 128, 255)`  `hsl(120, 100%, 40%)`
  ```

- [ ] **Картинки для светлой и тёмной темы [GitHub]** — тег `picture`

  ```markdown
  <picture>
    <source media="(prefers-color-scheme: dark)" srcset="logo-dark.png">
    <img alt="Логотип" src="logo-light.png">
  </picture>
  ```

- [ ] **Предложения правок (suggestion) [GitHub]** — только в комментариях код-ревью: кнопка «Commit suggestion» применяет правку в один клик

  ````markdown
  ```suggestion
  новая версия строки
  ```
  ````

- [ ] **Вставка фрагмента кода по ссылке [GitHub]** — постоянная ссылка на строки файла, вставленная в комментарий, разворачивается в сам код (получите её на странице файла: выделите строки → «Copy permalink»)

  ```markdown
  https://github.com/user/repo/blob/<commit-sha>/file.py#L10-L20
  ```

---

## Проверка совместимости

Фичи с пометкой **[GitHub]** в других редакторах покажутся как обычный текст. Чтобы проверить, как выглядит ваш файл за пределами GitHub, откройте его в нужном редакторе или в онлайн-превью (например, CommonMark Dingus).

Полная спецификация: <https://github.github.com/gfm/>
